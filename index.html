1. condition현재 Cart-Pole 상태 c = [x, ẋ, θ, θ̇].
2. noisy actionteacher action chunk a₀에 Gaussian noise를 섞어 aₜ를 만듭니다.
3. denoise + actεθ가 noise를 예측해 16-step action chunk를 복원하고 앞 4 step만 실행합니다.

실제로 학습된 모델

Learned εθ는 손으로 만든 denoise 애니메이션이 아니라 demonstration에서 학습한 36 → 64 → 64 → 16 SiLU MLP입니다. 입력은 noisy 16-action, 4-state condition, 16-d timestep embedding입니다. 브라우저에서는 int16로 양자화한 weight를 읽어 순수 JavaScript matrix multiply로 추론합니다.

Oracle은 왜 남겨두나?
Oracle ε는 forward corruption 때 사용한 정답 noise를 알고 있으므로 이상적인 reverse 기준입니다. Learned와 Oracle을 같은 noisy sample에서 비교하면 “diffusion 수학”과 “학습된 denoiser 오차”를 분리해서 볼 수 있습니다. Pure-noise generation은 Learned 모드에서만 제공합니다.
범위와 한계
v0.2는 upright 근방 Cart-Pole balance 교육용입니다. teacher는 discrete LQR이며, 이 결과를 SOTA 제어 성능이나 일반 manipulation Diffusion Policy 재현으로 해석하면 안 됩니다. 다음 단계는 multimodal action 분포와 vision/history conditioning입니다.
